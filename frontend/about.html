Background

Why I built this

A real estate degree, a gap in the market, and a question about what AI could do with it.

I graduated from the University of Reading with a BSc in Real Estate (2:1), with modules covering Real Estate Valuation, Development Appraisal, Applied Property Law and Asset Management. My final project received a First Class grade.

During my studies and job search I noticed a gap: the tools used by institutional property professionals — CoStar, EG Propertylink, agent research platforms — are expensive, complex, and largely inaccessible to graduates. I wanted to understand how modern technology could democratise access to this kind of intelligence, so I built my own version.

I had no coding background, so I built it the way I think a lot of work will be done from now on: I researched the data, wrote the specs, made every product and design call, and directed Claude to write the code. That meant learning enough Python, FastAPI and scikit-learn to read what it wrote, test it, and push back when it was wrong.

It worked well enough that I kept going. Hold now helps parents across the UK get their children into swimming lessons, and Unearthed launches this month.

I'm now looking to bring both sides of this — real estate knowledge and technical capability — into a graduate role at a firm where data, technology and property intersect.

West End Office Intelligence

How the platform works

A full-stack proptech platform: data pipeline, a backtested forecast, AI integration and a frontend, all deployed.

i.

Data Research & Pipeline

Researched and compiled quarterly market data across 8 Central London submarkets from published reports by Savills, CBRE, Colliers, Knight Frank and BNP Paribas. Built a structured CSV pipeline feeding a Python backend.

PythonPandasMarket Research

ii.

Machine Learning Forecasting

A ridge regression forecasts next quarter's vacancy change from momentum and relative take-up, four quarters ahead. Walk-forward backtesting shows it beats a no-change guess by 19%.

scikit-learnRidge RegressionBacktesting

iii.

FastAPI Backend

Built a production REST API with FastAPI, deployed on Railway. Endpoints serve forecasts, AI commentary, live web data, deal tracking and PDF generation, with Claude responses cached to keep costs down.

FastAPIRailwayREST API

iv.

Claude AI Integration

Integrated the Anthropic Claude API to write market commentary in the style of an agency research note, and to search the web for the latest published market figures and deal transactions.

Anthropic APIWeb SearchPrompt Engineering

v.

Frontend & Product Design

Vanilla HTML, CSS and JavaScript: an interactive submarket schematic, Chart.js visualisations, light and dark themes, and a saved data snapshot so the pages never sit blank when the API is down.

HTML/CSS/JSChart.jsSVGVercel

vi.

PDF Report Generation

Built an automated PDF report generator using ReportLab that produces a branded, institutional-quality research note on demand — including AI commentary, KPI tables, quarterly data breakdown and a disclaimer footer.

ReportLabPDF GenerationDocument Design

How I build

Judgement in, software out.

  1. Start with a real question

    Every project began with something I noticed. Graduates can't afford CoStar. Parents can't get a swimming place. Fans love spotting talent before anyone else.

  2. Direct the build

    I write the spec, make the product calls and direct Claude to write the code. I had no coding background, so I learned to read, test and question everything it produces.

  3. Ship it and be honest about it

    Everything here is deployed with real data. The West End forecast is backtested against a simple baseline, and Hold publishes how it measures what it reports.
