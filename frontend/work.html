PropTech for UK lettings
Working prototype

Samespot

Deposit disputes come down to one question: was that mark there at check-in? An agent films a slow walk round each room on a phone, in the browser with no app. Samespot builds a 3D map of the room, and at check-out it finds what changed and puts each mark beside the check-in photo of the same spot.

Every photo and video is fingerprinted with SHA-256, so the condition report and one-tap dispute pack sent to myDeposits, TDS or DPS can be shown to be untouched. The agent portal adds a fair wear-and-tear charge calculator, tenant self check-in and a property history.

In real rooms, change detection found all four test marks. Next up: cutting a 3 to 5 minute run on CPU down to seconds.
