Method

A forecast you can check

A forecast is only worth something if it beats the obvious guess. So this one is tested the hard way.

1

What it predicts

Next quarter's change in vacancy for each submarket, from two signals: last quarter's change (momentum) and take-up against that submarket's own average.

2

How it's tested

Walk-forward backtesting. For each past quarter the model is trained only on the quarters before it, then asked to predict it. 40 predictions in all.

3

How it scored

Off by 0.30 vacancy points on average, against 0.37 for assuming nothing changes. Small data, honest result, and the limits are written into the code.
